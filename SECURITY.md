# Security policy

Report suspected vulnerabilities through GitHub's **Report a vulnerability** on this repository's
Security tab when private reporting is available. If that option is unavailable, contact a
repository maintainer through a private channel listed on their public profile and request a secure
reporting channel before sending technical details. Do not post credentials or exploit details in a
public Issue.

Include the affected template reference and version, architecture, reproduction steps, expected
impact, and a proposed fix if you have one. Remove credentials and personal data from logs.
Coordinate public disclosure with the maintainer.

Security fixes target the latest release of each maintained template. A published template version
is immutable; fixes ship in a higher version. Base images and Features have their own upstream
security policies. Report an upstream issue to its maintainers as well when it affects components
outside this collection.

Templates create executable development environments. Review generated files and upstream
dependencies before opening an unfamiliar project in a container.
